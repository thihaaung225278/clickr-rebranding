# clickr-rebranding

Next.js App Router site for the Clickr rebrand.

## Getting Started

Use Node **≥20.9** (see `.nvmrc`):

```bash
nvm use
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Edit `src/app/page.tsx` — the page hot-reloads as you change it.

## Scripts

| Command | Purpose |
|---------|---------|
| `npm run dev` | Development server |
| `npm run build` | Production build |
| `npm start` | Serve production build |
| `npm run lint` | ESLint |

## Stack

- Next.js 16 (App Router, `src/app`)
- React 19 · TypeScript · Tailwind CSS v4 · npm
